# SOC Operations Dashboard

Real-time cybersecurity operations center dashboard with threat monitoring, global attack visualization, incident tracking, network traffic analysis, and system health monitoring.

## Features

- **Global Threat Map** — Geospatial visualization of real-time attack origins and targets
- **Threat Level Indicator** — Dynamic DEFCON-style severity assessment
- **Live Incident Feed** — Real-time SIEM-style event stream
- **Network Traffic Analysis** — Protocol distribution, bandwidth, and anomaly detection
- **Top Attackers** — IP profiling, geo-location, attack type classification
- **Firewall Log Stream** — Live blocked/allowed request monitoring
- **Vulnerability Scanner** — CVE severity breakdown and patch tracking
- **System Health** — Server infrastructure monitoring with CPU, RAM, disk, network metrics

## Tech Stack

- Next.js 14, React 18, TypeScript
- Tailwind CSS (dark military-grade theme)
- Recharts for data visualization

## Getting Started

```bash
npm install
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.
